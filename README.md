# egekibar/tap

Homebrew tap for [Shotcue](https://github.com/egekibar/Shotcue).

```bash
brew install --cask egekibar/tap/shotcue
```

Shotcue requires macOS 26 (Tahoe) on Apple silicon. It is not notarized, so the cask clears the quarantine flag after
installing. Shotcue updates itself from GitHub Releases; `brew upgrade --greedy` also works.
